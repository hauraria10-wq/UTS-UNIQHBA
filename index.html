Semua mata kuliah di bawah ini akan otomatis muncul pada pilihan Semester & Mata Kuliah di halaman login mahasiswa.

Mode: Edit Mata Kuliah
A. Identitas Mata Kuliah, Semester & Password Ujian

Mahasiswa wajib mengetik password ini saat memilih mata kuliah ini agar kelas/semester lain tidak bisa masuk.

B. Copy-Paste Soal Pilihan Ganda (Otomatis Terbaca)

Tempelkan (Paste) seluruh soal pilihan ganda dari Word/PDF/WA ke kotak ini. Tulis Kunci: C di bawah tiap soal (atau beri tanda * di depan opsi benar).

C. Copy-Paste Soal Esai / Studi Kasus (Opsional)

Pisahkan antar soal esai dengan baris kosong lalu nomor soal (1. ..., 2. ...). Kosongkan jika ujian hanya Pilihan Ganda.

D. Pratinjau & Simpan Mata Kuliah ke Server Ujian

Klik "Cek & Pratinjau Soal" untuk memastikan seluruh nomor dan kunci jawaban terbaca otomatis.

Info Sinkronisasi Online ke HP Mahasiswa (Klik untuk melihat SQL Supabase)

-- Jalankan sekali di SQL Editor Supabase agar daftar mata kuliah, password & soal otomatis muncul di HP semua mahasiswa:

CREATE TABLE IF NOT EXISTS pengaturan_ujian (
  id TEXT PRIMARY KEY,
  config JSONB NOT NULL,
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
ALTER TABLE pengaturan_ujian ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Akses penuh pengaturan ujian" ON pengaturan_ujian FOR ALL USING (true) WITH CHECK (true);
